# Rider v2

A web app for part-time delivery riders, built for my Cycle 1 project (GUI Design & Web Optimization). This is v2, made after my context mapping, interviews and ideation.

## Problem
Part-time delivery riders choose when to work without knowing how many orders to expect, because delivery apps only show demand after login. A wrong guess can mean unpaid waiting.

## Design goal
Part-time delivery riders feel confident about how much work they will get before they commit to a shift.

## Files
- index.html: page structure
- style.css: styling
- app.js: app logic
